# 摘要

基于模型的系统工程（Model-Based Systems Engineering，MBSE）是一种持续贯
穿系统整个研发生命周期的标准化建模方法。在系统的早期设计阶段，基于行为模型
对系统进行仿真，能够验证系统行为逻辑的正确性和合理性。此外，随着产品复杂度
逐渐提高，在早期设计阶段进行仿真验证，会避免因设计缺陷造成产品设计周期长，
设计成本大等问题。同时，设计人员也必须面对复杂的各类系统，其中包括混合系统。
因此在MBSE 中进行混合系统行为仿真具有重要意义。目前在MBSE中进行系统行
为仿真，主要存在两方面问题。一方面，用于系统行为仿真的工具平台依赖性强，与
建模工具没有很好地结合，导致建模与仿真过程繁琐。另一方面，由于复杂产品全生
命周期研发过程往往是一个多学科交叉开发的过程。进行系统行为建模时，领域工程
师采用不同领域专用建模语言（UML，SysML，UPDM等）建立各自领域的系统行为
模型。且针对于不同行为模型，采用的仿真工具往往也不一致。缺少一种语言对这些
建模语言的系统行为模型进行统一描述，以便于后续对这些行为模型进行仿真验证。
为此本文对复杂产品系统行为建模与仿真设计及实现进行了相关研究。 
（1）基于元元模型的系统行为建模方法研究。通过对系统行为模型的分析，采用
GOPPRR-E 元建模方法实现对不同领域建模语言（SysML和UML）描述的系统行为
模型的统一表达和构建。 
（2）支持混合自动机的系统行为描述研究。通过混合自动机理论建立混合系统行
为的描述机制，并与GOPPRR-E 元建模方法进行结合，解决混合自动机支持SysML
和UML系统行为模型的统一描述问题。 
（3）系统行为建模和仿真语言设计。在上述研究的基础上，提出了系统行为建模
与仿真语言。在多架构建模语言KARMA语言的基础上设计系统行为建模与仿真语言
的具体语法和抽象语法，使其具备描述系统行为的能力。 
（4）系统行为仿真实现。构建采用系统行为建模与仿真语言描述的行为模型的半
自动化仿真流程，并在建模工具MetaGraph中实现。该流程主要由仿真编译器和仿真
求解引擎构成，编译器对可执行的系统行为模型进行编译，仿真求解引擎对仿真编译
内容进行仿真。并在仿真流程的基础上，提出了多仿真文件合并和复合状态分解方法，
解决了多状态机联合仿真和复合状态仿真编译问题。 
（5）在上述理论研究的基础上，通过四种不同场景分别对复杂产品系统中状态机
图、活动图、序列图和多状态机图联合仿真进行仿真实现，验证了本文研究内容的可
行性和有效性。
