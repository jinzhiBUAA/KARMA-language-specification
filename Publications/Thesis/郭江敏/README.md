# 摘要

复杂系统的开发离不开架构设计，近年来系统规模及系统复杂程度急剧增长，基
于模型系统工程（Model-based Systems Engineering，MBSE）被越来越多地应用于复
杂系统的架构设计过程。MBSE方法以形式化的系统架构模型为核心，通过模型驱动
开发方法实现模型的（半）自动生成，保证模型信息可追溯性，提高开发效率。模型
转换是模型驱动开发的关键方法，然而，在多学科交叉的复杂系统架构设计场景下，
目前存在的模型转换方法存在许多不足之处，其具体表现为：1）缺乏支持多领域异构
模型的通用模型转换方法，导致多领域架构模型之间的转换需要应用多种转换方法，
开发难度增加 2）缺乏一种模型转换统一描述语言，在架构模型转换过程中需要用到
多种模型转换语言，导致架构师的学习成本增加。针对上述问题，本文提出了面向复
杂系统架构设计的模型转换方法和模型转换语言，对以下内容进行研究： 
（1）复杂系统架构模型转换理论与框架研究。在架构模型构建方法中主要介绍了
基于GOPPRR-E元元模型的元建模框架，实现多领域异构模型的统一表达，为跨域模
型转换奠定基础；在模型转换方面总结现有方法并给出本文的模型转换定义；最后提
出本文的模型转换框架。 
（2）基于图论的复杂系统架构模型转换方法研究。针对复杂系统架构设计场景下
多领域异构模型转换方法不统一的问题，基于图论将GOPPRR-E元建模框架中模型、
元模型映射为等价的图、类型图，模型转换规则映射为图转换规则，将异构领域的架
构模型转换问题转变为同构的图转换问题，实现系统架构模型的跨域模型转换。 
（3）架构模型转换正确性的形式化检验方法研究。针对架构模型转换可能出现缺
陷模型的问题，提出模型转换检验方法。首先给出模型转换正确性的形式化定义；接
着，基于类型图一致性验证理论，将模型转换正确性问题形式化描述为类型图一致性
验证问题。最后，提出模型转换自动验证流程，避免生成缺陷模型，确保模型转换正
确性。 
（4）架构模型转换统一描述语言研究。在上述研究基础上，提出模型转换统一描
述语言，以模型转换规则的形式实现架构模型转换的统一描述。重点引入模型模式的
概念并根据架构模型的结构特点，总结出四种典型的模型模式，并设计模型转换语言
的抽象语法和具体语法。最后，开发模型转换语言解析器和执行引擎，以实现模型转
换语言的描述能力。 
（5）在上述理论研究的基础上，以无人平台系统架构设计为案例，对本文提出的
模型转换方法和模型转换语言进行实例应用和验证。
