# 摘要

随着各国科技、军事实力的提高以及装备平台的不断更新换代，现代军队作战形态由机械化作战逐步发展到了智能化、信息化的作战;由单一兵种作战发展为一体化全域联合作战;由以有形作战发展为网络空间和认知域对抗的无形作战以及以人工智能为技术支撑的无人化作战。在以联合作战为主的新型战争态势下战斗规模愈发宏大，战争形势也越来越复杂，装备平台的单个能力指标的高精尖已不是最高要求，而整体体系所显示出来的综合能力的协同涌现更加关键。
传统的效能评估方法通常从装备体系的自身性能出发，而没有综合考虑装备平台的种类、数目及能力范围对体系效能产生的影响，且评估指标体系的构建往往存在人为因素大、说服力弱等问题。因此，本文研究了基于网络分析法和云重心评判法的效能评估流程，并提出标度准则与能力值的概念对传统方法进行改进。首先，针对现有网络分析法人为评价次数庞大、不具备复用性、无法自动执行等问题，本文提出了一种基于标度准则的网络分析法用于评估指标体系权重的计算。由于体系在作战过程中会产生大量的战场信息，不同种类的战场信息包含了不同重要程度的信息，同时体系组成子系统以及体系能力能够在建模中以数据流关系，即战场信息进行关联。因此，提出基于数据流关系的标度准则，对战场信息按照功能进行划分，并根据数据密级分配不同的标度值，形成标度准则，代替人为两两比较评价的方式进行重要程度比较。标度准则具备良好的可扩展性，能够根据作战背景、作战方式、数据信息的发展不断扩充细化，类似场景与体系能够采用一套标度准则进行自动化评价，提高了可复用性与评估效率。
其次，云重心效能评估方法虽然很好的处理了体系评估的随机性和模糊性但同样需要领域专家进行人为评价，耗时耗力，且没有考虑装备平台本身对能力指标的影响。因此，本文提出能力值的概念，对评估指标体系进行扩展，在能力指标层下添加装备平台层，将装备平台本身的固有能力、装备平台数目和能力覆盖范围等因素纳入考虑范围内，形成能力值生成机制。运用装备平台的能力值代替云重心主观打分的方式对能力指标进行评价，得到最终的体系效能评价。
最后，构建了预警探测体系，并将改进后的方法运用于场景的体系效能评估中，在不依赖于人为评价的条件下获得了该体系效能评估结果，验证了方法的可行性和有效性。
