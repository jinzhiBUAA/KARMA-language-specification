# 摘要

为了适应数据量和复杂性日益增长的系统工程建模需要，多粒度建模方法和
云端建模是系统工程目前最热门的课题。本文研究了多粒度建模方法论，详细对
比了视点选择法、一体化层次法、聚合解聚法进行建模的优劣、特征、应用场景，
总结了不同方法的应用领域，并基于聚合解聚法实现了多粒度建模的案例。本文
主要研究内容分为以下三部分。
首先，本文对系统工程、基于模型的系统工程做了简单介绍，简要说明了其
历史发展、当前发展方向。本文还对于多粒度建模语言及其架构、特征进行了论
述。然后，本文说明了多粒度模型技术中的方法论以及三种方法，提出了云技术
和多粒度模型技术的结合应用。
其次，本文提出了聚合解聚法适用于复杂系统建模的观点，提出了一种基于
多架构建模语言（KombinationofArchitecture Model Specification，KARMA）进行
多粒度建模的方法理论，并在MetaGraph软件中基于KARMA语言、聚合解聚方
法对航空发动机进行多粒度建模，详细分析了该案例中的粒度层次、粒度划分，最
后实现案例，并且对于模型中的模型元素一致性进行了分析。本文以该案例说明
了聚合解聚法和复杂系统建模的有效粘合性，相互贴合，并且使用软件对模型一
致性进行规范评估，能够有效解决聚合解聚法的劣势，放大其优势。
最后，本文提出了云端建模平台的需求，对此进行功能设计及实现，实现了
基于KARMA语言和GOPPRRE元模型架构的云端建模平台，对平台建模功能做
了详细介绍。本文设计开发的云端建模平台可基于已有元模型库和社区案例进行
快速开发，也可以从头进行元模型库设计。基于云端建模平台，本文设计实现了
基于指挥—侦查—作战的作战体系案例建模，对其粒度层次、具体模型进行详细
说明，并对模型一致性进行分析，说明了该云端建模平台对于多粒度模型建模技
术的有效匹配，进一步论证了聚合解聚法在复杂系统建模中的应用正确性。
