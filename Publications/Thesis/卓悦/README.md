# 摘要

随着现代系统协同化和一体化的发展，系统间的资源交互以及系统和环境间
的资源交互越来越频繁，系统间越来越呈现体系化和网络化趋势。基于MBSE的
系统设计方法面临跨学科、跨领域等挑战，需要将MBSE的系统设计方法扩展至
体系的结构设计，以应对复杂场景下的体系结构设计需求。复杂场景下的体系建
模与仿真研究，对于大型作战场景下体系的研究和设计具有重要意义。本文以作
战场景为研究对象，研究实际体系的模型构建和联动仿真问题。
首先，针对复杂场景下体系概念模型构建时，模型要素不明确、模型扩展性
差、建模过程主观因素影响大等问题。本文提出了一种基于DoDAF架构框架的体
系的概念模型建模方法。将实际体系要素层次化和结构化，以作战场景为主要背
景，把体系模型要素依次分为使命级、场景级和活动级三个层次，并分别明确不
同体系层次的体系要素，形成实际体系的结构化描述。在得到体系结构化描述之
后，通过DoDAF架构框架中的全景视点、能力视点、系统视点和作战视点，将各
层的结构化要素以DoDAF视点模型的形式化表达。得到实际体系的DoDAF概念
模型。DoDAF模型构建遵循通过元数据组保证一致性。体系要素的层次化也提供
了一种体系分析方式，实现体系模型的不断细化。也使模型构建人员可对不同层
次不同要素协作建模。为实际体系结构的分析和维护提供依据。
其次，针对实际体系的仿真模型构建时，体系的问题域与仿真域的一致性问
题，本文提出了一种基于CIF混合状态机的体系仿真模型建模方法。在体系活动
级要素的基础上，将体系层次进一步扩展，扩展为事件级、装备级和参数级三个
层次，分别明确不同层次的体系要素，通过层次的扩展将体系活动映射到执行装
备。通过定义CIF仿真模型与装备模型的映射规则，构建基于装备级要素和参数
级要素的CIF仿真模型。并根据映射规则开发模型模板化工具，简化仿真模型开
发流程，提高仿真模型代码的复用性。
