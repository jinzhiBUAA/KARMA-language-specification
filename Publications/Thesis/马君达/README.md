# 摘要

随着装备系统复杂度的提高，基于模型的系统工程（MBSE, Model-Based 
Systems Engineering）能够有效支持复杂系统全生命周期的需求、设计、分析、验证
和确认活动，提高装备设计效率。然而面向装备的复杂系统架构建模往往涉及多阶
段多领域，建模语言规范的图类型有限，导致缺乏对复杂系统全生命周期的描述；
不同建模语言语义的不一致，导致模型的歧义和质量下降；异构的建模工具构建的
模型底层数据不一致，导致模型集成和交互困难，从而降低了装备整体数字化研发
效率。因此，针对以上问题，论文主要研究内容如下：
（1）复杂系统架构多视图统一建模框架。为研究复杂系统多视图统一建模，构
建面向复杂装备的基于霍尔模型的多视图统一建模框架，从系统维、逻辑维、学科
领域维三个维度实现装备的生命周期过程，提出了多视图统一建模的分层抽象模型
构建、基于图论有向图的抽象模型形式化表征、多视图统一建模语言表达三个层次
递进的技术路线。
（2）基于GOPPRR-E（Graph, Object, Point, Property, Relationship, Role, Extension）
元素的分层抽象模型研究。针对装备复杂系统生命周期多阶段架构模型缺少通用抽
象元素描述，不足以支持复杂系统统一表达的问题，进行统一建模分层抽象模型研
究。首先将结合系统工程实践扩展的 GOPPRR-E 元元模型，作为本文语言的底层模
型；然后结合MOF（Meta-Object Facility）框架定义分层抽象模型，表达出各层的建
模元素以及使用这些元素的规则，该分层抽象模型是定义复杂系统架构模型形式化
表征的基础。
（3）基于图论有向图的抽象模型统一形式化表征研究。针对装备复杂系统架构
模型的表达缺少完整的形式化语义，导致模型的理论研究缺失的问题，进行模型统
一形式化表征研究。首先介绍图论的基本概念，其次基于元模型层类型图和模型层
实例图开展元模型及模型形式化表征，再次形式化表征基于扩展约束的模型满足性
约束，最后形式化表征项目和语言。以此实现数学逻辑对模型本质的精准定义，支
持多视图统一建模语言的语法构建。
（4）多视图统一建模语言表达研究。针对支持复杂系统生命周期多阶段架构建
模的多种建模语言底层数据异构导致模型表达不一致、集成困难等问题，开展多视图
统一建模语言表达研究。首先建立语言构建方法，然后指定元模型及模型的抽象
语法，明确各元素的类及组合关系；最后定义具体语法，指定抽象语法中的元模型
及模型等的显式表达，最终实现多视图统一建模语言规范的构建。 
（5）复杂系统架构多视图集成表达验证平台设计与验证。通过搭建基于模型系
统工程的多视图集成表达验证平台进行多视图统一建模关键技术的验证。首先在平
台中分析BPMN、DMN、OPM、UPDM和SysML等5种建模语言，表明多视图统一
建模语言满足各语言抽象能力，并通过可视化元模型规范技术、连接器类型规范技
术等4种技术的对比分析，表明多视图统一建模语言的适用能力；然后验证多视图统
一建模的性能指标：集成性、完整性和一致性。通过构建 11 种元模型进行智能电动
汽车架构设计，验证多视图统一建模语言对复杂系统多阶段架构建模集成性的支持；
通过对建模过程中 28 个模型、459 个对象等的形式化表达，验证对复杂系统生命周
期架构建模完整性和表达一致性的支持。
