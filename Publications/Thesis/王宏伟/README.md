# 摘要

随着系统复杂度的增加，系统设计与组织效率显著降低，因此工
业界广泛采用系统工程方法对系统全生命周期中需求、设计、分析、
验证和确认过程进行形式化表达。目前设计师在实现多学科、跨领域
交叉融合的复杂系统设计过程中往往采用通用建模语言SysML、UML
或特定域建模语言如EAST-ADL、DoDAF等进行异构模型的设计与开
发，在此基础上采用基于SysML的XMI标准进行不同模型之间的数
据交互。然而，多种建模语言采用不同语法和语义进行设计，其不一
致性增大了异构模型统一表述的难度；此外，设计上下游不同设计人
员采用不同建模工具实现特定模型的开发增加了模型底层数据的交互
难度，而XMI标准仅对SysML提供相关的接口，缺少普适性。 
综述，目前业务人员在进行系统工程实践时需要一种统一建模方
法以实现不同建模语言之间的打通，从而融合不同建模语言的优点，
提高设计效率；同时基于上述建模方法设计一种数据交互方法实现系
统设计周期中异构模型信息的统一描述及互操作。 
本文在GOPPRR 方法的基础上设计一套以 MBSE 为核心领域的
多架构建模方法，可以在此基础上按照需求、功能、逻辑、架构的映
射规律实现复杂系统全生命周期中所涉及的所有架构建模；并在此基
础上提出一套基于多架构建模的本体框架实现异构模型数据的一致性
表达，并通过SQWRL及SPARQL语言对该框架进行理论验证，通过
基于多种建模语言的模型数据与本体框架的双向转化及互操作对该框
架进行工程验证。。
