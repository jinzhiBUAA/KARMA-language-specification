# 摘要

武器装备体系（Weapon system-of-systems,WSoS）是一个复杂的具备多构成要
素的动态系统，由于 WSoS 的高度复杂性以及不确定性，研究人员难以建立能够
准确表征WSoS的网络模型。因此，WSoS网络的风险评估也会因此受到一定程度
的限制，评估结果也较难验证。本文以复杂网络理论为基础，重点围绕武器装备网
络模型优化以及风险评估等方面开展了研究。论文的主要研究工作和创新点包括： 
1）针对现有模型难以准确描述WSoS网络的问题，本文设计了一种武器装备
双层复用网络演化模型。首先，将装备映射到不同功能层并建立了多层复用网络模
型。其次，在深入分析多层网络节点利用率、链路损失率和演化时间以及重叠性与
度相关性指标之后，将多层网络聚合简化为双层复用网络模型。最后，基于WSoS
网络的特点对武器装备双层复用网络的演化算法进行了优化，提高了网络演化效
率、重要组件识别准确率和识别效率。 
2）针对传统的武器装备体系风险评估手段无法综合评估复杂的动态WSoS网
络的问题，本文在上述研究成果的基础上融合了基于拓扑特征的指标与武器装备
的功能指标，设计了一种基于多指标融合的WSoS风险评估框架。首先，分析了拓
扑指标与功能指标的联系，构建了风险指标层次结构，并根据武器装备的重要物理
参数指标对网络进行加权，再基于双层复用网络拓扑结构计算出 WSoS 风险评估
综合指标。然后，构建了基于多指标融合的 WSoS 风险评估框架。通过该框架对
WSoS网络中的装备节点和链路进行风险评估以及评估值排序。 
3）本文在实验室项目所搭建的作战概念模型动态推演可视化平台的的基础上
对三四章的研究成果进行技术验证。首先简述了可视化平台的功能，然后基于该平
台构建了我方 WSoS 网络拦截敌军攻击的复合型任务。通过作战任务的推演实验
来评估WSoS网络的作战效能，实验得到 WSoS网络中装备或链路的作战效能排
序结果，验证了基于多指标融合的 WSoS 风险评估框架对作战风险防控具有实际
意义。
