# 摘要

基于模型的系统工程（Model-BasedSystemsEngineering, MBSE）提供了一种统一
的、可共享的、可追溯的系统设计方法，帮助设计人员更好地理解系统，并在整个系
统生命周期中保持模型的一致性。MBSE建模方法论是这一领域的产物，旨在指导设
计人员设计出“正确”的系统。然而，随着MBSE应用的广泛和深入，目前对于方法
论的设计和应用存在一定的问题，表现在以下几个方面：（1）现有方法论抽象的描
述方式无法适应多层级、多领域的复杂装备系统开发场景，其定制化和可扩展性较弱；
（2）缺乏支持构建系统全局模型的建模语言，系统模型之间缺乏显式的关联关系，
给系统架构的维护和扩展带来困难；（3）方法论与建模工具的融合不足，导致方法
论对系统设计的驱动并没有取得理想的效果。
本文针对上述问题，开展了复杂装备系统导航式建模技术的研究，主要包括以下
四个方面：
（1）复杂装备系统导航式建模技术。首先介绍了本文的技术基础——KARMA
语言及其建模工具，并分析了解决上述问题的设计需求。然后，提出了复杂装备系统
导航式建模框架，以元对象机制和数据建模为总体框架，为本文提供技术指导。最后，
讨论了本研究的应用。
（2）面向导航式建模的元模型设计。首先，利用实体关系图分析了元模型所需
覆盖的元素，保障所用术语的全面和统一。然后，基于元元模型GOPPRR-E（该元元
模型包括图、对象、点、属性、关系、角色和扩展七个要素）和业务流程标注，对实
体关系图进行扩展，设计实体的图形化表达，即元模型，旨在为方法论的流程建模提
供手段，达到流程驱动设计和串联架构模型的效果。
（3）复杂装备系统导航式建模语言设计。首先，研究了GOPPRR-E元元模型与
可扩展标记语言（ExtensibleMarkupLanguage, XML）的映射关系。在此基础上，设
计了导航式建模语言的抽象语法和具体语法，用XML实现了对流程模型的存储和描
述。最后，基于所提建模语言设计了流程模型、XML模型和文件结构模型的自动转
换方法，提升了设计的自动化水平，减少了设计人员重复的建模工作。
（4）复杂装备系统导航式建模系统设计及验证。首先，设计了支持上述流程模
型、XML模型和文件结构模型构建及转换的建模系统，并根据实际应用需求开发了
流程模型与设计、分析、仿真和验证所需功能的接口。然后，通过对比分析和案例分
析，验证了复杂装备系统导航式建模技术的正确性和工具的可行性。
