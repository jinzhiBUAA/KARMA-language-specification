# 摘要

随着武器装备和作战指挥系统信息化程度越来越高，未来的战场环境将会愈
加复杂多元。复杂作战态势场景的仿真过程中会产生海量的数据和信息，从这些数
据中快速、高效的获取指挥人员所需要的信息并进行可视化呈现以便快速决策是
传统综合信息平台亟待提升的能力。 
为此，本文研究了基于复杂场景下动态仿真数据处理与可视化展示的关键技
术以解决传统面向战场的仿真可视化一体平台中仿真文件构建复杂以及可视化效
果单一的问题。 
首先，本文提出基于已建立的体系模型，采用一种基于混合状态机
（Compositional Interchange Format, CIF）语言的系统行为描述流程对模型的行为状
态进行描述，该流程能够快速、高效的根据体系模型编写对应的仿真文件。对已建
立的仿真文件，本文采用 CIF 工具链中的仿真求解器进行仿真验证，求解结果与
ADS-B 数据相比对得到近似结果，表明本文所述方法论的科学性。 
其次，本文研究了基于CIF动态仿真数据使用Cesium三维数字地球进行数据
可视化展示的关键技术，提出了一种解决仿真模块与可视化模块之间时间同步的
方式，使仿真数据动态生成时能够在可视化模块同步预览。本文研究了复杂战场环
境的可视化构建以及该环境下的多种可视化效果，包括装备之间的信息线连通、爆
炸、雷达扫描、雷达干扰等效果。传统的仿真－可视化数据展示工具通常只具备本
地演示功能，本文研究了基于Web技术的可视化大屏展示手段，提出了一种支持
多设备、跨平台的大屏集成展示方式。 
最后，本文根据佩洛西访台案例的媒体公开资料构建了体系模型。根据该模型，
本文完成了复杂系统的行为仿真描述和可视化场景搭建，实现了动态仿真数据与
可视化模块联动展示的功能。同时将相关模块在大屏进行集成，解决了传统可视化
平台展示手段单一问题，验证了本文提出的系统描述文件构建流程与可视化处理
关键技术的有效性和可行性。
