# Model for Landing Gear System of Special Aircraft (Version 1.0)

This is a behavior model about Landing Gear System of Special Aircraft based on KARMA language verified by Hybridsim Automata.

## Scope of the Model 

This case study employs the KARMA language to construct a behavioral state transition view of the landing gear brake system. Furthermore, it verifies the behavior model using a hybrid automaton.
