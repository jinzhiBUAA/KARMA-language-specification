# Mars rover model based on MOFLP methodology (Version 1.0)

This is a metamodel template specification for Mars rover model based on MOFLP methodology


## Scope of the Metamodel 

This Metamodel template aims to provide basic modeling elements for Mars rover model based on MOFLP methodology. Based on the SysML language in the Metagraph 2.0 tool, and under the guidance of the MOFLP methodology, a model of each level of the Mars rover system was established to analyze the system.

## About this version

The Mars rover is roughly modeled as a whole, and some specific information and descriptions are insufficient.


## Status

This version is a practice of MOFLP methodology, and iterations will be followed up in the future.
